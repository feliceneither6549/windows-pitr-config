pitr-config — short guide

Configuring Point-in-time restore on Windows 11.

What this tool is for

Windows 11 can take full system snapshots and roll the machine back to an earlier state. How often it does that and how long a snapshot is kept can only be set on the Enterprise edition — everywhere else those two dropdowns are greyed out.

This tool sets them anyway. The restriction lives in the Settings user interface, not in the engine underneath, and the engine takes its configuration from a place the tool can write to directly.

A snapshot whenever one is wanted

The green button at the top of the window, Create snapshot now, creates a restore point immediately — no waiting for the schedule, and no setting touched. One click worth spending before a driver installation, an edit to the registry, or a first run of unfamiliar software.

It takes a moment: the task runs, Windows writes the shadow copy, and the new point then appears in the list below. Since the scheduled task otherwise runs only while the machine is idle, the button lifts that condition for this one run and restores it afterwards.

Getting started

Double-click pitr-config.cmd. It asks for administrator rights itself, then opens a window. Nothing is written until a button is pressed.

The language follows the Windows display language; the buttons in the top right switch it at any time.

On start the tool asks GitHub whether a newer version exists and shows a line with a link if there is one. It never downloads or installs anything by itself, and a failed check stays silent. Starting it as pitr-config.cmd noupdate skips the check.

The buttons

Create snapshot nowCreates a restore point at once, without changing any setting. The highlighted button at the top of the window.
ApplyWrites the selected settings. A new frequency takes effect the next time the scheduled task runs.
Apply and run nowWrites the settings and runs the task immediately, so a restore point is created and the schedule is recalculated at once.
RefreshRe-reads the current state.
Reset everythingRemoves every value the tool has written, after asking. Windows returns to its own defaults.

The settings

  • Feature enabled — switches Point-in-time restore on or off.
  • Frequency — 1 to 24 hours between restore points.
  • Retention — 1 to 7 days before a point is deleted automatically.
  • Maximum storage — 2 to 50 GB for all restore points together.

Each list starts with Windows default, which removes that single override again. Underneath each list, in grey, stands the value currently in effect and where it comes from.

Three things worth knowing

Frequency is an earliest possible interval, not a promise. Restore points are only created while the system is idle. If the machine is in use, or switched off, the run is postponed and a slot can be skipped entirely. Setting one hour on a machine used all day will not produce twenty-four points. The window shows the task status, so a run that is waiting stays visible.

Only the Windows drive is covered. Other partitions and other disks are not included, not even on the same physical disk. Data there is neither protected nor rolled back, and still needs a backup of its own.

This is an unofficial route. The configuration values are not documented by Microsoft. A future Windows release may change them, at which point the normal Windows behaviour simply applies again.

Undoing everything

Reset everything removes all of it in one step. Existing restore points are never deleted by this tool — it only changes configuration.

pitr-config — Kurzanleitung

Die Zeitpunktwiederherstellung von Windows 11 einstellen.

Wofür das Werkzeug da ist

Windows 11 kann vollständige Systemabbilder anlegen und den Rechner auf einen früheren Stand zurücksetzen. Wie oft das geschieht und wie lange ein Abbild aufgehoben wird, lässt sich nur auf der Enterprise-Edition einstellen — überall sonst sind diese beiden Auswahlfelder ausgegraut.

Dieses Werkzeug setzt sie trotzdem. Die Sperre sitzt allein in der Oberfläche der Einstellungen, nicht in der darunterliegenden Engine, und die Engine liest ihre Konfiguration von einer Stelle, die das Werkzeug direkt beschreiben kann.

Ein Schnappschuss, wann immer er gebraucht wird

Die grüne Schaltfläche oben im Fenster, Schnappschuss jetzt erstellen, legt sofort einen Wiederherstellungspunkt an — ohne auf den Zeitplan zu warten und ohne dass sich an einer Einstellung etwas ändert. Ein Klick, der sich vor einer Treiberinstallation, einem Eingriff in die Registry oder dem ersten Start unbekannter Software lohnt.

Es dauert einen Moment: Die Aufgabe läuft, Windows schreibt die Schattenkopie, danach erscheint der neue Punkt in der Liste darunter. Weil die geplante Aufgabe sonst nur im Leerlauf läuft, hebt die Schaltfläche diese Bedingung für diesen einen Lauf auf und stellt sie danach wieder her.

Erste Schritte

pitr-config.cmd doppelklicken. Die Datei fordert selbst Administratorrechte an und öffnet ein Fenster. Geschrieben wird erst beim Druck auf eine Schaltfläche.

Die Sprache richtet sich nach der Windows-Anzeigesprache; die Schaltflächen oben rechts stellen sie jederzeit um.

Beim Start fragt das Werkzeug bei GitHub nach, ob es eine neuere Fassung gibt, und zeigt dann eine Zeile mit Link. Heruntergeladen oder installiert wird nie etwas von allein, und eine fehlgeschlagene Abfrage bleibt stumm. Mit pitr-config.cmd noupdate unterbleibt die Abfrage.

Die Schaltflächen

Schnappschuss jetzt erstellenLegt sofort einen Wiederherstellungspunkt an, ohne eine Einstellung zu ändern. Die hervorgehobene Schaltfläche oben im Fenster.
ÜbernehmenSchreibt die gewählten Einstellungen. Eine neue Häufigkeit wird beim nächsten Lauf der geplanten Aufgabe wirksam.
Übernehmen und sofort ausführenSchreibt die Einstellungen und stößt die Aufgabe direkt an, sodass sofort ein Punkt entsteht und der Zeitplan neu berechnet wird.
AktualisierenLiest den aktuellen Zustand neu ein.
Alles zurücksetzenEntfernt nach Rückfrage alle vom Werkzeug geschriebenen Werte. Windows kehrt zu seinen eigenen Vorgaben zurück.

Die Einstellungen

  • Feature aktiv — schaltet die Zeitpunktwiederherstellung ein oder aus.
  • Häufigkeit — 1 bis 24 Stunden Abstand zwischen zwei Punkten.
  • Aufbewahrung — 1 bis 7 Tage, bis ein Punkt automatisch gelöscht wird.
  • Maximaler Speicherplatz — 2 bis 50 GB für alle Punkte zusammen.

Jede Liste beginnt mit Windows-Standard; damit wird genau diese eine Überschreibung wieder entfernt. Unter jeder Liste steht in Grau der aktuell wirksame Wert und woher er stammt.

Drei Dinge, die man wissen sollte

Die Häufigkeit ist ein frühestmöglicher Abstand, keine Zusage. Wiederherstellungspunkte entstehen nur, wenn das System im Leerlauf ist. Wird der Rechner benutzt oder ist er ausgeschaltet, verschiebt sich der Lauf, und ein Termin kann ganz ausfallen. Wer eine Stunde einstellt und den Rechner den ganzen Tag benutzt, bekommt keine vierundzwanzig Punkte. Das Fenster zeigt den Status der Aufgabe an, damit erkennbar ist, wann ein Lauf wartet.

Erfasst wird nur das Windows-Laufwerk. Weitere Partitionen und weitere Festplatten sind nicht dabei — auch nicht auf derselben physischen Platte. Daten dort werden weder geschützt noch zurückgesetzt und brauchen weiterhin eine eigene Sicherung.

Das ist ein inoffizieller Weg. Die Konfigurationswerte sind von Microsoft nicht dokumentiert. Eine künftige Windows-Version kann sie ändern; dann gilt wieder das normale Verhalten von Windows.

Alles rückgängig machen

Alles zurücksetzen entfernt sämtliche Werte in einem Schritt. Vorhandene Wiederherstellungspunkte löscht das Werkzeug nie — es ändert ausschließlich die Konfiguration.

pitr-config — guide rapide

Configurer Point-in-time restore sous Windows 11.

À quoi sert cet outil

Windows 11 peut créer des instantanés complets du système et ramener la machine à un état antérieur. La fréquence à laquelle il le fait et la durée de conservation d'un instantané ne peuvent être réglées que sur l'édition Enterprise : ailleurs, ces deux listes sont grisées.

Cet outil les règle malgré tout. La restriction se trouve uniquement dans l'interface des Paramètres, pas dans le moteur sous-jacent, et ce moteur lit sa configuration à un endroit où l'outil peut écrire directement.

Un instantané dès qu'on en a besoin

Le bouton vert en haut de la fenêtre, Créer un instantané maintenant, crée immédiatement un point de restauration — sans attendre la planification et sans toucher au moindre réglage. Un clic qui vaut la peine avant l'installation d'un pilote, une intervention dans le registre ou le premier lancement d'un logiciel inconnu.

Cela prend un moment : la tâche s'exécute, Windows écrit le cliché instantané, puis le nouveau point apparaît dans la liste en dessous. Comme la tâche planifiée ne s'exécute autrement que pendant l'inactivité, le bouton lève cette condition pour cette seule exécution et la rétablit ensuite.

Premiers pas

Double-clic sur pitr-config.cmd. Le fichier demande lui-même les droits d'administrateur et ouvre une fenêtre. Rien n'est écrit tant qu'aucun bouton n'a été actionné.

La langue suit la langue d'affichage de Windows ; les boutons en haut à droite la changent à tout moment.

Au démarrage, l'outil demande à GitHub s'il existe une version plus récente et affiche le cas échéant une ligne avec un lien. Il ne télécharge et n'installe jamais rien de lui-même, et un échec de la vérification reste silencieux. Lancer pitr-config.cmd noupdate supprime cette vérification.

Les boutons

Créer un instantané maintenantCrée aussitôt un point de restauration, sans modifier le moindre réglage. Le bouton mis en évidence en haut de la fenêtre.
AppliquerÉcrit les réglages choisis. Une nouvelle fréquence prend effet à la prochaine exécution de la tâche planifiée.
Appliquer et exécuter maintenantÉcrit les réglages et lance la tâche immédiatement : un point est créé et la planification est recalculée aussitôt.
ActualiserRelit l'état actuel.
Tout réinitialiserSupprime, après confirmation, toutes les valeurs écrites par l'outil. Windows revient à ses propres valeurs par défaut.

Les réglages

  • Fonctionnalité activée — active ou désactive Point-in-time restore.
  • Fréquence — de 1 à 24 heures entre deux points de restauration.
  • Conservation — de 1 à 7 jours avant la suppression automatique d'un point.
  • Espace maximal — de 2 à 50 Go pour l'ensemble des points.

Chaque liste commence par Valeur par défaut de Windows, ce qui supprime à nouveau ce remplacement précis. Sous chaque liste, en gris, figure la valeur actuellement appliquée et sa provenance.

Trois choses à savoir

La fréquence est un intervalle minimal, pas une promesse. Les points de restauration ne sont créés que lorsque le système est inactif. Si la machine est utilisée, ou si elle est éteinte, l'exécution est reportée et un créneau peut être ignoré. Régler une heure sur une machine utilisée toute la journée ne produira pas vingt-quatre points. La fenêtre affiche l'état de la tâche, ce qui rend visible une exécution en attente.

Seul le lecteur Windows est pris en compte. Les autres partitions et les autres disques sont exclus, même sur le même disque physique. Les données qui s'y trouvent ne sont ni protégées ni restaurées et ont toujours besoin de leur propre sauvegarde.

Il s'agit d'une voie non officielle. Les valeurs de configuration ne sont pas documentées par Microsoft. Une future version de Windows peut les modifier ; le comportement normal de Windows s'appliquera alors de nouveau.

Tout annuler

Tout réinitialiser supprime l'ensemble en une seule étape. L'outil ne supprime jamais les points de restauration existants : il ne modifie que la configuration.

pitr-config — guía breve

Configurar Point-in-time restore en Windows 11.

Para qué sirve esta herramienta

Windows 11 puede crear instantáneas completas del sistema y devolver el equipo a un estado anterior. Con qué frecuencia lo hace y cuánto tiempo conserva cada instantánea solo puede ajustarse en la edición Enterprise: en las demás, esas dos listas aparecen atenuadas.

Esta herramienta las ajusta de todos modos. La restricción está únicamente en la interfaz de Configuración, no en el motor que hay debajo, y ese motor lee su configuración de un lugar en el que la herramienta puede escribir directamente.

Una instantánea cuando haga falta

El botón verde de la parte superior de la ventana, Crear instantánea ahora, crea de inmediato un punto de restauración: sin esperar a la programación y sin tocar ningún ajuste. Un clic que merece la pena antes de instalar un controlador, modificar el registro o abrir por primera vez un programa desconocido.

Tarda un momento: la tarea se ejecuta, Windows escribe la instantánea de volumen y después el punto nuevo aparece en la lista de abajo. Como por lo demás la tarea programada solo se ejecuta con el equipo inactivo, el botón levanta esa condición para esta única ejecución y la restablece al terminar.

Primeros pasos

Doble clic en pitr-config.cmd. El archivo solicita por sí mismo permisos de administrador y abre una ventana. No se escribe nada hasta que pulse un botón.

El idioma se toma del idioma de presentación de Windows; los botones de arriba a la derecha lo cambian en cualquier momento.

Al iniciarse, la herramienta pregunta a GitHub si existe una versión más reciente y, en ese caso, muestra una línea con un enlace. Nunca descarga ni instala nada por su cuenta, y si la comprobación falla no dice nada. Iniciarla como pitr-config.cmd noupdate omite la comprobación.

Los botones

Crear instantánea ahoraCrea al instante un punto de restauración, sin cambiar ningún ajuste. El botón destacado en la parte superior de la ventana.
AplicarEscribe los ajustes elegidos. Una frecuencia nueva surte efecto en la siguiente ejecución de la tarea programada.
Aplicar y ejecutar ahoraEscribe los ajustes y ejecuta la tarea de inmediato, de modo que se crea un punto y el calendario se recalcula al instante.
ActualizarVuelve a leer el estado actual.
Restablecer todoElimina, tras confirmación, todos los valores escritos por la herramienta. Windows vuelve a sus propios valores predeterminados.

Los ajustes

  • Función activada — activa o desactiva Point-in-time restore.
  • Frecuencia — de 1 a 24 horas entre puntos de restauración.
  • Conservación — de 1 a 7 días antes de que un punto se elimine automáticamente.
  • Espacio máximo — de 2 a 50 GB para todos los puntos en conjunto.

Cada lista empieza por Valor predeterminado de Windows, que elimina de nuevo esa sobrescritura concreta. Debajo de cada lista, en gris, se ve el valor actualmente en vigor y de dónde procede.

Tres cosas que conviene saber

La frecuencia es un intervalo mínimo, no una promesa. Los puntos de restauración solo se crean cuando el sistema está inactivo. Si está usando el equipo, o si está apagado, la ejecución se aplaza y una cita puede omitirse por completo. Configurar una hora en un equipo que se usa todo el día no producirá veinticuatro puntos. La ventana muestra el estado de la tarea, de modo que una ejecución en espera queda a la vista.

Solo se incluye la unidad de Windows. Otras particiones y otros discos quedan fuera, incluso en el mismo disco físico. Los datos que haya allí no se protegen ni se revierten, y siguen necesitando su propia copia de seguridad.

Esta es una vía no oficial. Los valores de configuración no están documentados por Microsoft. Una versión futura de Windows puede cambiarlos; entonces volverá a aplicarse simplemente el comportamiento normal de Windows.

Deshacerlo todo

Restablecer todo lo elimina en un solo paso. La herramienta nunca borra puntos de restauración existentes: solo cambia la configuración.

pitr-config — guia rápido

Configurar o Point-in-time restore no Windows 11.

Para que serve esta ferramenta

O Windows 11 pode criar instantâneos completos do sistema e reverter o computador para um estado anterior. Com que frequência isso acontece e por quanto tempo um instantâneo é mantido só podem ser ajustados na edição Enterprise — nas demais, essas duas listas ficam esmaecidas.

Esta ferramenta ajusta esses valores mesmo assim. A restrição está apenas na interface do app Configurações, não no mecanismo por baixo, e esse mecanismo lê sua configuração de um lugar onde a ferramenta pode gravar diretamente.

Um instantâneo quando for preciso

O botão verde no alto da janela, Criar instantâneo agora, cria imediatamente um ponto de restauração: sem esperar pelo agendamento e sem alterar nenhuma configuração. Um clique que vale a pena antes de instalar um driver, mexer no registro ou abrir pela primeira vez um programa desconhecido.

Leva um instante: a tarefa é executada, o Windows grava a cópia de sombra e o novo ponto aparece na lista abaixo. Como a tarefa agendada, de resto, só é executada com o computador ocioso, o botão suspende essa condição nessa única execução e a restabelece em seguida.

Primeiros passos

Duplo clique em pitr-config.cmd. O arquivo solicita por conta própria direitos de administrador e abre uma janela. Nada é gravado até que um botão seja pressionado.

O idioma segue o idioma de exibição do Windows; os botões no canto superior direito mudam o idioma a qualquer momento.

Ao iniciar, a ferramenta pergunta ao GitHub se existe uma versão mais nova e, nesse caso, mostra uma linha com um link. Ela nunca baixa nem instala nada por conta própria, e uma verificação malsucedida fica em silêncio. Iniciar como pitr-config.cmd noupdate dispensa a verificação.

Os botões

Criar instantâneo agoraCria na hora um ponto de restauração, sem alterar nenhuma configuração. O botão destacado no alto da janela.
AplicarGrava as configurações escolhidas. Uma nova frequência entra em vigor na próxima execução da tarefa agendada.
Aplicar e executar agoraGrava as configurações e executa a tarefa imediatamente, criando um ponto e recalculando o agendamento na hora.
AtualizarRelê o estado atual.
Redefinir tudoRemove, após confirmação, todos os valores gravados pela ferramenta. O Windows volta aos próprios padrões.

As configurações

  • Recurso ativado — liga ou desliga o Point-in-time restore.
  • Frequência — de 1 a 24 horas entre pontos de restauração.
  • Retenção — de 1 a 7 dias até um ponto ser excluído automaticamente.
  • Espaço máximo — de 2 a 50 GB para todos os pontos juntos.

Cada lista começa com Padrão do Windows, o que remove novamente aquela substituição específica. Abaixo de cada lista, em cinza, aparece o valor atualmente em vigor e de onde ele vem.

Três coisas que vale saber

A frequência é um intervalo mínimo, não uma promessa. Os pontos de restauração só são criados quando o sistema está ocioso. Se o computador estiver em uso, ou desligado, a execução é adiada e um horário pode ser pulado por completo. Configurar uma hora em um computador usado o dia inteiro não vai gerar vinte e quatro pontos. A janela mostra o status da tarefa, de modo que uma execução aguardando fica visível.

Apenas a unidade do Windows é incluída. Outras partições e outros discos ficam de fora, mesmo no mesmo disco físico. Os dados ali não são protegidos nem revertidos e continuam precisando do próprio backup.

Este é um caminho não oficial. Os valores de configuração não são documentados pela Microsoft. Uma versão futura do Windows pode alterá-los; nesse caso volta a valer simplesmente o comportamento normal do Windows.

Desfazer tudo

Redefinir tudo remove tudo em uma única etapa. A ferramenta nunca exclui pontos de restauração existentes — ela apenas altera a configuração.
